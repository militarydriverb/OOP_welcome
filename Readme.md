# OOP_welcome
## Это проект представляет собой практическую реализацию создания классов
## Описание основных сущностей и инициализацию объектов.
Определение атрибутов для каждого класса, их тип и начальное значение.

Инициализация классов и передача в них атрибутов.

# Дополнение 1
Для класса Category список товаров сделан приватным атрибутом, 
чтобы к нему нельзя было получить доступ извне. 
Для добавления товаров в категорию реализован специальный метод add_product().
В классе Category передаются объект класса Product и уже он записывать в приватный 
атрибут списка товаров.

# Дополнение 2
Так как атрибут со списком товаров приватный, то атрибут «список товаров категории» у нас освободился,
но программа лишена возможности выводить список товаров. 
Чтобы вернуть возможность просмотра товаров, реализован геттер,
который будет выводить список товаров в виде строк в формате:
Название продукта, 80 руб. Остаток: 15 шт.

# Дополнение 3
Для класса Product создан класс-метод new_product, который будет принимать на вход параметры товара
в словаре и возвращать созданный объект класса Product.

# Дополнение 4
Для класса Product атрибут цены установлен приватным и описан геттеры и сеттеры. 
В сеттере реализована проверка: в случае если цена равна или ниже нуля, 
в консоль выводится сообщение “Цена не должна быть нулевая или отрицательная”,
при этом новая цена не устанавливается.

## Наследование
# Дополнение 1
Выделены две категории товаров Smartphone и LawnGrass дочерние к классу Products
Помимо имеющихся у родительского класса свойств для каждой категории добавлены 
свои свойства.

# Дополнения 2
Функциональность сложения доработана таким образом, чтобы можно было складывать 
товары только из одинаковых классов продуктов, в противном случае выводиться ошибка 
TypeError

# Дополнение 3
Метод добавления защищен таким образом, что кроме смартфонов, травы газонной или 
других продуктов, в список нельзя было добавлять ничего другого.
Метод, который добавляет продукт в категорию, доработан таким образом, 
чтобы не было возможности добавить вместо продукта или его наследников любой другой объект.

## Множественное наследование
# Дополнение 1
Создан базовый абстрактный класс с именем BaseProduct, который станет родительским для класса продуктов.
Классы «Смартфон» и «Трава газонная» остаются наследниками класса Product
и тем самым наследуют все свойства абстрактного класса.
Важно выделить общую функциональность, которая должна быть у каждого продукта, и описать ее в абстрактном классе.

# Дополнение 2
Реализован класс-миксин, который будет при создании объекта, то есть при работе метода 
__init__, печатать в консоль информацию о том, от какого класса и с какими параметрами был создан объект
Миксин добавлен в цепочку наследования класса Product.

# Дополнение 3
Для новой функциональности написаны тесты

## Исключения
# Дополнение 1
В случае если пользователь создает товар (метод__init__) с нулевым количеством, вызывать исключение 
ValueError, которое будет выдавать сообщение: Товар с нулевым количеством не может быть добавлен.
При этом прерывать выполнение программы.

# Дополнение 2
В классе Category реализован новый метод, который подсчитывает средний ценник всех товаров. 
С помощью исключений обрабатывается случай, когда в категории нет товаров и сумма всех товаров будет делиться на ноль. 
Если такое происходит, возвращайте ноль.

# Дополнение 3
Для новой функциональности написаны тесты.
При этом тесты, написанные ранее выполняются без ошибок
